# Dicionário de motion · 30 efeitos para pedir à IA

Trinta efeitos de animação com o nome em português, o termo exato para usar no pedido à IA e um prompt pronto para copiar, cada um rodando na tela.

**Página:** https://simiao-cavalcante.github.io/dicionario-de-motion/

## O que tem dentro

1. Um teste interativo em que o mesmo quadrado obedece a pedidos diferentes
2. Três informações que fazem o pedido funcionar
3. Os 30 efeitos em cinco grupos: Entradas, Ritmo, Texto, Câmera e Transições
4. Um pedido completo para colar no Claude, no ChatGPT ou em qualquer ferramenta que gere animação por código

## Sobre

Montado por [Simião Cavalcante](https://instagram.com/simiao_cavalcante), procurador do Município do Rio de Janeiro e professor, que edita os próprios reels com IA. A ideia de reunir esses termos num dicionário veio de um [post de Douglas Januário no X](https://x.com/douglasjanuario/status/2110048988900540486), que montou a primeira versão com 24 efeitos.

A página é HTML estático, sem dependências de build. As animações são feitas só com CSS.
